# Head Tracker+Voice+Instructor

**Обзор головой в авиасимуляторах с помощью iPhone — плюс голосовые команды и инструктор, которые работают вместе.**

## Что это

Head Tracker+Voice+Instructor превращает ваш iPhone в трекер головы для авиасимуляторов на компьютере с Windows. Посмотрели влево — вид в кабине повернулся влево. Та же программа понимает голосовые команды кабины и включает инструктора, который ведёт вас по процедурам.

| Часть | Что вы получаете |
|---|---|
| **Обзор головой** | За головой следит фронтальная камера iPhone (та, что работает для Face ID). Шесть направлений движения: поворот, кивок, наклон вбок, сдвиг вперёд/назад, в стороны, вверх/вниз. Без ИК-клипсы, без веб-камеры, без дополнительного оборудования. Если лицо закрыто на несколько секунд, слежение возвращается само. |
| **Голосовые команды** | Скажите «шасси выпустить» — программа нажмёт нужную клавишу в игре. Английский, французский, русский, немецкий, итальянский. |
| **Инструктор** | Ведёт вас шаг за шагом по процедурам вашего самолёта (запуск двигателя, взлёт, посадка), произносит следующий шаг вслух, показывает шаги на iPhone, а после полёта даёт журнал полёта и разбор. |

Обычно это три отдельные программы, которые никогда не задумывались для совместной работы. Здесь это одна система: одна настройка, одно окно, один iPhone.

## Что нужно

- Windows 10 или 11 (для установки права администратора не нужны).
- iPhone с Face ID (iPhone X и новее), iOS 16 или новее.
- Кабель между iPhone и компьютером или одна сеть Wi-Fi для обоих.
- Поддерживаемый симулятор (см. ниже).

## Совместимость

Проверенным отмечено только то, что мы действительно проверили.

| Симулятор | Статус |
